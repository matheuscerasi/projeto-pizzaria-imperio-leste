
# Modelagem do Banco de Dados — Império Leste Pizzaria

Este documento apresenta os modelos conceitual e lógico do banco de dados desenvolvido para o **Sistema de Precificação e Controle Administrativo da Império Leste Pizzaria**.

O objetivo da modelagem é organizar as informações utilizadas pelo estabelecimento, permitindo o controle de produtos, ingredientes, custos, margens de lucro, preços praticados pelos concorrentes e registros de vendas.

---

## 1. Modelo Conceitual (DER)

O **Diagrama Entidade-Relacionamento (DER)** representa as entidades, seus atributos, relacionamentos e cardinalidades.

Esse modelo permite compreender a estrutura do sistema antes da implementação do banco de dados.

### Visualizar Modelo Conceitual

🔗 **[Acessar DER Conceitual no brModelo Web](https://app.brmodeloweb.com/publicview/6af4cfe1e43309563f04a62a)**

---

## 2. Modelo Lógico

O **Modelo Lógico** representa a organização das tabelas do banco de dados, incluindo seus atributos, chaves primárias (PK), chaves estrangeiras (FK) e relacionamentos.

Esse modelo serve como referência para a implementação do banco de dados relacional em SQL.

## 3. Ferramenta Utilizada

Os dois modelos foram desenvolvidos utilizando o **brModelo Web**, ferramenta voltada à modelagem de bancos de dados.

- **Modelo Conceitual:** representação das entidades, atributos e regras de relacionamento.
- **Modelo Lógico:** representação da estrutura relacional utilizada como base para a implementação do banco de dados.

---

## 4. Objetivo da Modelagem

A modelagem foi desenvolvida para auxiliar a administração da Império Leste Pizzaria, principalmente no processo de precificação.

O sistema tem como objetivos:

- Organizar o cadastro de produtos e ingredientes.
- Registrar os custos relacionados aos produtos.
- Controlar margens de lucro e preços de venda.
- Permitir a comparação de preços com concorrentes.
- Registrar vendas realizadas pelo estabelecimento.
- Auxiliar o proprietário na análise de custos e resultados.

**Observação:** o sistema é destinado ao uso administrativo do estabelecimento. Não se trata de uma plataforma para clientes realizarem pedidos online.
