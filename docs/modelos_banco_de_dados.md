# Modelagem do Banco de Dados — Império Leste Pizzaria

Este documento apresenta os modelos conceitual e lógico do banco de dados desenvolvido para o Sistema de Precificação e Controle Administrativo da Império Leste Pizzaria.

## 1. Modelo Conceitual (DER)

O modelo conceitual representa as entidades, seus atributos e relacionamentos, incluindo as cardinalidades e regras de negócio.

**[Visualizar o DER Conceitual no brModelo Web](https://app.brmodeloweb.com/publicview/6af4cfe1e43309563f04a62a)**

## 2. Modelo Lógico

O modelo lógico representa a estrutura das tabelas, suas chaves primárias, chaves estrangeiras e relacionamentos, servindo como base para a implementação do banco de dados.

**[Visualizar o Modelo Lógico no brModelo Web](https://app.brmodeloweb.com/publicview/6af4d275e43309563f04a65d)**

## 3. Ferramenta utilizada

Os modelos foram desenvolvidos utilizando o brModelo Web.

**Observação:** os links permitem visualizar os modelos publicamente. A possibilidade de criar cópias editáveis depende das permissões de importação configuradas no brModelo Web.
